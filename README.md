# MyAccountApp

A React Native mobile application built with Expo Router for user registration and form handling.

### Features

- User registration with form validation.
- Password matching validation.
- Data transfer between screens using Expo Router.
- Review and edit registration details.
- Success screen with a personalized greeting.
- Age calculation and 18+ age restriction.

### Technologies

- React Native
- Expo
- Expo Router
- JavaScript

### Run the Application

```bash
npm install
npx expo start
```
